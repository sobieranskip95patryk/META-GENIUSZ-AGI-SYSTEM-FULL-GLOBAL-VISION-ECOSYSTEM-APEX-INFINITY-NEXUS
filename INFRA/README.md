# GOK:AI - Księga Genesis

## Infrastruktura
Katalog `INFRA` zawiera narzędzia niezbędne do utrzymania operacyjnego i skalowania systemu AGI.

### Uruchomienie
1. Zainstaluj zależności: `pip install -r INFRA/requirements.txt`
2. Uruchom bootstrap: `python CORE/02_Memory/bootstrap.py`

### Zasoby
- **EnvironmentSimulator**: Bezpieczna piaskownica.
- **ScalingManager**: Zarządzanie mocą obliczeniową.
