## �🏗️ Architektura Systemu

System działa w architekturze **Klient-Serwer** z wykorzystaniem hybrydowych endpointów.

```mermaid
graph TD
    User((Użytkownik)) -->|Http Request| Frontend[MTAQuest Frontend]
    Frontend -->|JSON| Bridge[Bridge Server (Flask)]
    Bridge -->|Weryfikacja Logiczna| Core[GOK Core: Python]
    Bridge -->|Zapytanie Kreatywne| API[Google Gemini API]
    Core -->|Logika| Bridge
    API -->|Odpowiedź| Bridge
    Bridge -->|JSON Response| Frontend
```

- **Lokalizacja Core:** `CORE/` (Logika, Wektoryzacja)
- **Lokalizacja Infra:** `INFRA/` (Serwery, Bridge, API)
- **Lokalizacja Frontend:** `FRONTEND/` (HTML, JS, Assets)

## 🛠️ Instalacja i Uruchomienie

### 1. Klonowanie Repozytorium
Pobierz kod źródłowy "Mózgu Boga" na swoją maszynę:
```bash
git clone https://github.com/sobieranskip95patryk/AGI_GOK.git
cd AGI_GOK
```

### 2. Przygotowanie Środowiska
Utwórz i aktywuj wirtualne środowisko Python:
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / Mac
python3 -m venv .venv
source .venv/bin/activate
```

Zainstaluj wymagane biblioteki:
```bash
pip install -r requirements.txt
```

### 3. Konfiguracja Kluczy
Utwórz plik `.env` w głównym katalogu projektu:
```env
GEMINI_API_KEY=Twoj_Klucz_API_Google
PORT=5000
```

### 4. Uruchomienie (Deployment)
Uruchom serwer mostu, aby ożywić system:
```bash
python INFRA/Services/bridge_server.py
```
System będzie dostępny pod adresem: `http://localhost:5000`.
